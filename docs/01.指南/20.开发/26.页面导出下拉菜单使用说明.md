## 功能列表

| 功能 | 图标 | 说明 |
|------|------|------|
| 复制页面 | 📋 | 将页面以 Markdown 格式复制到剪贴板 |
| 以 Markdown 格式查看 | 📝 | 在新标签页以纯文本查看 Markdown |
| 下载 Markdown | ⬇️ | 下载当前页面的 Markdown 文件 |

## 使用方式

### 1. 点击下拉按钮

点击页面标题右侧的「📋 复制页面 ▼」按钮，展开下拉菜单。

### 2. 选择功能

从下拉菜单中选择需要的功能：

- **复制页面**：点击后 Markdown 内容会复制到剪贴板，显示成功提示
- **以 Markdown 格式查看**：点击后在新标签页打开 Markdown 源文件
- **下载 Markdown**：点击后浏览器自动下载 Markdown 文件

### 3. 关闭菜单

- 点击菜单外部区域
- 再次点击下拉按钮
- 选择功能后自动关闭

## 交互特性

- **悬停效果**：菜单项悬停时显示背景色
- **点击外部关闭**：点击菜单外部自动关闭
- **动画过渡**：菜单展开/收起有平滑动画
- **箭头旋转**：下拉箭头在展开时旋转 180 度
- **Toast 提示**：操作成功后显示提示消息

## 移动端适配

在移动设备上（屏幕宽度 < 768px）：

- 按钮文字自动隐藏，只显示图标
- 下拉菜单位置自动调整
- 保持完整功能


## 常见问题

### Q: 按钮不显示？

A: 检查：
1. 组件文件是否存在
2. 布局文件是否正确导入组件
3. 开发服务器是否重启

### Q: 下拉菜单不展开？

A: 检查：
1. 浏览器控制台是否有 JavaScript 错误
2. Vue 组件是否正确渲染
3. CSS 样式是否正确加载

### Q: 点击功能没反应？

A: 检查：
1. Markdown 文件路径是否正确
2. 浏览器是否允许剪贴板权限
3. 网络请求是否成功

### Q: 如何添加更多功能？

A: 在 `PageExportDropdown.vue` 中添加新的菜单项：

```vue
<div class="dropdown-item" @click="newFunction">
  <span class="item-icon">✨</span>
  <div class="item-content">
    <div class="item-title">新功能</div>
    <div class="item-desc">功能描述</div>
  </div>
</div>
```

然后在 `script` 中实现 `newFunction` 方法。
