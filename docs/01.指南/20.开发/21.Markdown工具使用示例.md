# Markdown 工具使用示例

本文档演示如何在 VitePress 文档中使用 Markdown 导出工具。

## 组件已全局注册

`DocMarkdownTools` 组件已在全局注册，可以在任何页面中使用。

## 使用方式

### 方式一：在导航栏中使用（推荐）

修改 `docs/.vitepress/config.ts`，在主题配置中添加：

```typescript
export default defineConfig({
  themeConfig: {
    // ... 其他配置
    outline: {
      level: [2, 4],
      label: "本页导航",
    },
    // 添加自定义工具
    tools: {
      markdown: {
        enabled: true,
      },
    },
  },
})
```

### 方式二：在页面内容中使用

在 Markdown 文件中直接使用组件：

```markdown
# 我的文档

<DocMarkdownTools />

这里是文档内容...
```

### 方式三：自定义布局

创建自定义布局文件，将组件添加到合适的位置。

## 样式定制

### 修改按钮颜色

```scss
.doc-markdown-tools {
  .tool-btn {
    &:hover {
      border-color: var(--vp-c-brand);
      color: var(--vp-c-brand);
    }
  }
}
```

### 修改按钮位置

```scss
.doc-markdown-tools {
  position: absolute;
  top: 10px;
  right: 20px;
}
```

## 注意事项

1. 确保 Markdown 文件可以通过 HTTP 访问
2. 生产环境需要正确配置 CORS
3. 移动端会自动隐藏按钮文字

## 效果预览

访问任意文档页面，点击右上角即可看到 Markdown 导出工具。
