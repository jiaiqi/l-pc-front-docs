## 可能的问题及解决方案

### 问题 1: 按钮不显示

**原因**: 组件未正确注册或样式问题

**解决方案**:
```bash
# 清除缓存并重启
rm -rf docs/.vitepress/cache
npm run docs:dev
```

### 问题 2: 点击按钮无反应

**原因**: JavaScript 错误或权限问题

**解决方案**:
1. 打开浏览器控制台查看错误
2. 检查是否允许剪贴板权限
3. 确认 Markdown 文件路径正确

### 问题 3: 下载失败

**原因**: CORS 限制或文件路径错误

**解决方案**:
1. 检查网络请求
2. 确认 `markdownPath` 计算正确
3. 开发环境通常无此问题

### 问题 4: Toast 提示不显示

**原因**: 样式未加载

**解决方案**:
```typescript
// 确保在 index.ts 中导入了样式
import "./styles/markdown-tools.scss";
```

### 注意事项

1. **Markdown 文件访问**: 确保生产环境可以访问 `.md` 文件
2. **CORS 配置**: 如果 Markdown 文件在 CDN 上，需要配置 CORS
3. **静态文件部署**: 确保所有 `.md` 文件都部署到服务器

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/docs/.vitepress/dist;
    
    # 支持 Markdown 文件访问
    location ~* \.md$ {
        add_header Content-Type text/markdown;
        add_header Access-Control-Allow-Origin *;
    }
    
    # 其他配置...
}
```
