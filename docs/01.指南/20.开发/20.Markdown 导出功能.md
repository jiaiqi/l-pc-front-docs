# Markdown 导出功能

> **支持复制 Markdown 和下载 Markdown 文件的便捷功能**

本文档介绍如何使用文档站的 Markdown 导出功能，包括复制 Markdown 内容和下载 Markdown 文件。

## 功能说明

文档站右上角提供了 Markdown 导出工具，包含以下功能：

| 功能 | 说明 | 图标 |
|------|------|------|
| 复制为 Markdown | 将当前页面的 Markdown 源内容复制到剪贴板 | 📋 |
| 下载 Markdown | 下载当前页面的 Markdown 源文件 | ⬇️ |

## 使用方法

### 复制为 Markdown

1. 打开任意文档页面
2. 点击右上角的「📋 复制」按钮
3. Markdown 内容会自动复制到剪贴板
4. 看到成功提示后，即可在其他地方粘贴使用

**使用场景：**
- 快速分享文档内容
- 在代码编辑器中查看源码
- 引用文档内容到其他文档
- 备份重要文档片段

### 下载 Markdown

1. 打开任意文档页面
2. 点击右上角的「⬇️ 下载 MD」按钮
3. Markdown 文件会自动下载到本地
4. 文件名与当前文档名称一致

**使用场景：**
- 离线阅读文档
- 本地编辑和修改
- 版本控制和备份
- 导入到其他文档系统

## 注意事项

### 内容范围

- 复制和下载的内容为 Markdown 源文件
- 包含完整的 Markdown 格式和 Frontmatter 元数据
- 不包含渲染后的 HTML 样式

### 文件路径

- 下载的文件名与当前文档路径一致
- 例如：访问 `/guide/overview` 会下载 `overview.md`

### 浏览器兼容性

- **现代浏览器**：完全支持（Chrome、Edge、Firefox、Safari）
- **移动端**：支持基础功能，按钮文字会自动隐藏
- **旧版浏览器**：部分功能可能不兼容（如 Clipboard API）

### 网络要求

- 需要能够访问 Markdown 源文件
- 如果部署在 CDN 上，需要确保 CORS 配置正确
- 本地开发环境无此限制

### 核心功能

**复制功能：**

```typescript
const copyMarkdown = async () => {
  const content = await getMarkdownContent()
  await navigator.clipboard.writeText(content)
  showMessage('✅ Markdown 已复制到剪贴板！', 'success')
}
```

**下载功能：**

```typescript
const downloadMarkdown = async () => {
  const content = await getMarkdownContent()
  const blob = new Blob([content], { type: 'text/markdown;charset=utf-8' })
  const url = URL.createObjectURL(blob)
  const link = document.createElement('a')
  link.href = url
  link.download = fileName
  link.click()
  URL.revokeObjectURL(url)
}
```

## 常见问题

### Q: 点击按钮没有反应？

A: 检查以下几点：
1. 浏览器是否支持 Clipboard API
2. 是否授予了剪贴板权限
3. 查看浏览器控制台是否有错误信息
4. 确认 Markdown 文件路径正确

### Q: 下载的文件打不开？

A: 确保：
1. 使用支持 Markdown 的编辑器打开
2. 文件编码为 UTF-8
3. 文件扩展名为 `.md`

### Q: 复制的内容不完整？

A: 可能原因：
1. Markdown 源文件本身不完整
2. 网络请求失败
3. CORS 跨域限制

### Q: 可以在移动端使用吗？

A: 可以，移动端会自动隐藏按钮文字，只显示图标。但部分功能（如下载）在移动端可能受限。

## 扩展功能

如需添加更多功能（如下载 PDF），可以参考组件代码进行扩展。

**添加下载 PDF 按钮示例：**

```vue
<button 
  class="tool-btn" 
  @click="downloadPdf" 
  title="下载 PDF"
>
  <span class="icon">📄</span>
  <span class="text">下载 PDF</span>
</button>
```

然后在 `script` 部分实现 `downloadPdf` 方法即可。
