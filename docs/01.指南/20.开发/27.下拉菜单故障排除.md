# 下拉菜单故障排除

## 问题：点击按钮没有下拉菜单

### 已修复的问题

经过检查，发现以下问题并修复：

1. **事件冒泡问题**：点击按钮时事件冒泡导致菜单立即关闭
   - **修复**：添加 `@click.stop` 阻止事件冒泡

2. **z-index 层级问题**：下拉菜单可能被其他元素遮挡
   - **修复**：将 `z-index` 从 1000 提升到 9999

3. **事件监听模式**：使用 capture 模式确保正确捕获点击事件
   - **修复**：添加 `true` 参数使用 capture 模式

### 修复后的代码

```vue
<template>
  <div class="page-export-dropdown" ref="dropdownRef">
    <!-- 添加 .stop 阻止事件冒泡 -->
    <button @click.stop="toggleDropdown">
      📋 复制页面 ▼
    </button>
    
    <div v-show="isOpen" class="dropdown-menu">
      <!-- 菜单项也添加 .stop -->
      <div @click.stop="copyMarkdown">...</div>
    </div>
  </div>
</template>

<script>
// 使用 capture 模式监听点击事件
document.addEventListener('click', handleClickOutside, true)
</script>

<style>
.dropdown-menu {
  z-index: 9999; /* 提高层级 */
}
</style>
```

## 常见问题

### Q: 点击按钮控制台没有输出？

A: 可能是：
1. 组件没有正确加载
2. JavaScript 报错阻止了执行
3. 事件绑定失败

**检查方法：**
```bash
# 检查文件是否存在
cat docs/.vitepress/theme/components/PageExportDropdown.vue

# 检查布局文件是否正确导入
grep "PageExportDropdown" docs/.vitepress/theme/components/TeekLayoutProvider.vue
```

### Q: 菜单元素存在但不显示？

A: 可能是：
1. CSS 样式问题
2. `v-show` 为 `false`
3. 被其他元素遮挡

**检查方法：**

在控制台执行：
```javascript
// 检查菜单元素
const menu = document.querySelector('.dropdown-menu')
console.log('Menu exists:', !!menu)
console.log('Menu display:', menu?.style.display)
console.log('Menu visibility:', menu?.style.visibility)

// 强制显示菜单
if (menu) {
  menu.style.display = 'block'
  menu.style.visibility = 'visible'
}
```

### Q: 菜单显示但点击选项没反应？

A: 可能是：
1. 点击事件没有绑定
2. 方法执行出错
3. 事件被阻止

**检查方法：**

在控制台执行：
```javascript
// 检查菜单项
const items = document.querySelectorAll('.dropdown-item')
items.forEach((item, index) => {
  console.log(`Item ${index}:`, item.onclick)
})
```

### Q: 菜单位置不对？

A: 可能是 CSS 定位问题。

**检查方法：**

在控制台执行：
```javascript
const menu = document.querySelector('.dropdown-menu')
console.log('Menu position:', getComputedStyle(menu).position)
console.log('Menu top:', getComputedStyle(menu).top)
console.log('Menu right:', getComputedStyle(menu).right)
console.log('Menu z-index:', getComputedStyle(menu).zIndex)
```

## 如果还是不行

### 方案 1：使用简单的实现

创建一个简化版本，不使用下拉动画：

```vue
<template>
  <div class="simple-export">
    <button @click="showMenu = !showMenu">📋 复制页面 ▼</button>
    <div v-if="showMenu" class="simple-menu">
      <div @click="copyMarkdown">复制页面</div>
      <div @click="downloadMarkdown">下载 Markdown</div>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'
const showMenu = ref(false)

const copyMarkdown = () => {
  // 复制逻辑
  showMenu.value = false
}

const downloadMarkdown = () => {
  // 下载逻辑
  showMenu.value = false
}
</script>
```

### 方案 2：使用第三方库

安装使用 `vue3-dropdown` 或类似库：

```bash
npm install vue3-dropdown
```

### 方案 3：直接使用两个按钮

不使用下拉菜单，直接显示两个按钮：

```vue
<template>
  <div class="export-buttons">
    <button @click="copyMarkdown">📋 复制</button>
    <button @click="downloadMarkdown">⬇️ 下载</button>
  </div>
</template>
```
