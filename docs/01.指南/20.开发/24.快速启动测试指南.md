# 快速启动测试指南

## 第一步：启动开发服务器

```bash
# 在项目根目录执行
npm run docs:dev
```

等待服务器启动完成，通常会显示：

```
VITEPRESS v1.6.3  ready in 500 ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
```

## 第二步：访问文档

打开浏览器访问：`http://localhost:5173`

## 第三步：测试 Markdown 导出功能

### 测试复制功能

1. 打开任意文档页面（如：http://localhost:5173/guide/overview）
2. 查看页面右上角，应该能看到两个按钮：
   - 📋 复制
   - ⬇️ 下载 MD
3. 点击「📋 复制」按钮
4. 等待 Toast 提示：「✅ Markdown 已复制到剪贴板！」
5. 在文本编辑器中粘贴（Ctrl+V 或 Cmd+V）
6. 确认粘贴的内容是 Markdown 格式

### 测试下载功能

1. 在任意文档页面
2. 点击「⬇️ 下载 MD」按钮
3. 浏览器会自动下载文件
4. 检查下载的文件名是否正确（如：`overview.md`）
5. 用文本编辑器打开下载的文件
6. 确认内容完整

## 第四步：检查响应式设计

### 桌面端

- 按钮应该显示图标和文字
- 悬停时有颜色变化和上移动画
- 点击有反馈效果

### 移动端（或缩小浏览器窗口）

1. 打开浏览器开发者工具（F12）
2. 切换到设备模式（Ctrl+Shift+M）
3. 选择移动设备（如 iPhone 12）
4. 按钮文字应该自动隐藏
5. 只显示图标
6. 点击功能正常

## 第五步：检查 Toast 提示

### 成功提示

- 点击「复制」或「下载」按钮
- 页面顶部中央显示绿色边框的提示
- 提示内容带有 ✅ 图标
- 3 秒后自动消失

### 错误提示

1. 打开浏览器开发者工具
2. 切换到 Network 标签
3. 阻止 Markdown 文件请求
4. 点击按钮
5. 应该显示红色边框的错误提示
6. 提示内容带有 ❌ 图标

## 常见问题排查

### 问题 1: 看不到按钮

**检查步骤:**

```bash
# 1. 清除缓存
rm -rf docs/.vitepress/cache

# 2. 重新安装依赖
rm -rf node_modules
npm install

# 3. 重启服务器
npm run docs:dev
```

**检查文件:**

```bash
# 确认组件文件存在
ls docs/.vitepress/theme/components/DocMarkdownTools.vue

# 确认样式文件存在
ls docs/.vitepress/theme/styles/markdown-tools.scss

# 确认主题配置正确
cat docs/.vitepress/theme/index.ts
```

### 问题 2: 点击按钮没反应

**检查控制台:**

1. 按 F12 打开开发者工具
2. 切换到 Console 标签
3. 点击按钮
4. 查看是否有错误信息

**常见错误:**

- `Failed to fetch`: Markdown 文件路径错误
- `Clipboard API denied`: 剪贴板权限被拒绝
- `Cannot read property`: 组件未正确注册

**解决方案:**

```typescript
// 检查 index.ts 中的组件注册
export default {
  extends: Teek,
  Layout: TeekLayoutProvider,
  enhanceApp({ app }) {
    app.component('DocMarkdownTools', DocMarkdownTools); // 确保这行存在
  },
};
```

### 问题 3: Toast 不显示

**检查样式:**

```bash
# 确认样式文件已导入
grep "markdown-tools.scss" docs/.vitepress/theme/index.ts
```

**手动测试:**

在浏览器控制台执行：

```javascript
const toast = document.createElement('div')
toast.className = 'markdown-tool-toast markdown-tool-toast-success'
toast.textContent = '测试提示'
document.body.appendChild(toast)
setTimeout(() => toast.classList.add('show'), 10)
```

应该能看到测试提示。

### 问题 4: 下载失败

**检查网络请求:**

1. F12 打开开发者工具
2. Network 标签
3. 点击下载按钮
4. 查看是否有 `.md` 文件请求
5. 检查响应状态码（应该是 200）

**CORS 问题:**

如果看到 CORS 错误，需要在服务器配置 CORS：

```nginx
# Nginx 配置
location ~* \.md$ {
    add_header Access-Control-Allow-Origin *;
}
```

## 性能测试

### 加载时间

使用浏览器开发者工具：

1. F12 打开开发者工具
2. Performance 标签
3. 点击录制按钮
4. 刷新页面
5. 查看组件加载时间

**目标:**
- 组件加载 < 100ms
- 复制响应 < 500ms
- 下载响应 < 1s

### 文件大小

```bash
# 查看组件大小
wc -c docs/.vitepress/theme/components/DocMarkdownTools.vue
# 应该 < 5KB

# 查看样式大小
wc -c docs/.vitepress/theme/styles/markdown-tools.scss
# 应该 < 2KB
```
