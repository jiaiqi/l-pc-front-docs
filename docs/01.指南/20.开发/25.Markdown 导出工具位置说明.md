# Markdown 导出工具位置说明

## 工具位置

Markdown 导出工具现在显示在**文档页面右侧边栏的顶部**（目录上方）。

### 视觉效果

```
┌─────────────────────────────────────────┐
│           文档内容区域                   │
│                                         │
│  # 标题                                  │
│  内容...                                │
│                                         │
└─────────────────────────────────────────┘
         │
         │ 右侧边栏
         ▼
┌─────────────────────┐
│  📋 导出选项         │ ← 标题
│                     │
│  📋 复制            │ ← 复制按钮
│  ⬇️ 下载 MD         │ ← 下载按钮
│                     │
├─────────────────────┤
│  📑 本页导航         │ ← 目录
│  - 第一节            │
│  - 第二节            │
│  - 第三节            │
└─────────────────────┘
```

## 为什么放在这里？

1. **符合用户习惯**：右侧边栏是 VitePress 文档的标准工具区域
2. **不干扰阅读**：不会遮挡文档主要内容
3. **易于发现**：在目录上方，用户浏览目录时容易看到
4. **响应式友好**：移动端会自动隐藏边栏，保持界面简洁

## 样式特点

- **卡片式设计**：带有背景色和边框，与目录区分
- **标题标识**："导出选项"标题清晰标识功能
- **圆角边框**：8px 圆角，现代化设计
- **主题适配**：自动适配亮色/暗色主题

## 如何使用

### 复制 Markdown

1. 打开任意文档页面
2. 在右侧边栏找到"导出选项"卡片
3. 点击「📋 复制」按钮
4. 看到成功提示："✅ Markdown 已复制到剪贴板！"
5. 在需要的地方粘贴（Ctrl+V 或 Cmd+V）

### 下载 Markdown

1. 打开任意文档页面
2. 在右侧边栏找到"导出选项"卡片
3. 点击「⬇️ 下载 MD」按钮
4. 浏览器自动下载文件
5. 文件名与当前文档一致（如：`overview.md`）

## 移动端适配

在移动设备上（屏幕宽度 < 768px）：

- 右侧边栏会自动隐藏
- Markdown 工具也会随之隐藏
- 保持移动端界面简洁
- 如需使用，请在桌面浏览器中访问

## 常见问题

### Q: 还是看不到工具？

A: 请尝试以下步骤：

1. **清除缓存**
   ```bash
   rm -rf docs/.vitepress/cache
   npm run docs:dev
   ```

2. **检查文件**
   ```bash
   # 确认组件文件存在
   ls docs/.vitepress/theme/components/DocMarkdownTools.vue
   
   # 确认布局文件已修改
   cat docs/.vitepress/theme/components/TeekLayoutProvider.vue
   ```

3. **检查浏览器控制台**
   - 按 F12 打开开发者工具
   - 查看 Console 是否有错误
   - 查看 Network 是否有失败的请求

### Q: 工具显示但点击没反应？

A: 检查：
1. 浏览器控制台是否有 JavaScript 错误
2. 是否允许剪贴板权限
3. Markdown 文件路径是否正确

### Q: 样式不对？

A: 检查：
1. SCSS 文件是否正确导入
2. 主题变量是否正确
3. 浏览器是否支持 CSS 变量

## 技术实现

### 组件集成

```vue
<!-- TeekLayoutProvider.vue -->
<script setup>
import DocMarkdownTools from "./DocMarkdownTools.vue";
</script>

<template>
  <Teek.Layout>
    <template #aside-outline-before>
      <div class="markdown-tools-container">
        <div class="markdown-tools-title">导出选项</div>
        <DocMarkdownTools />
      </div>
    </template>
  </Teek.Layout>
</template>
```

```scss
.markdown-tools-container {

    color: var(--vp-c-text-1);

  }

```
