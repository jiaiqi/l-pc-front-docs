本文档详细介绍如何在页面中配置组件联动功能，实现组件间的数据交互。

## 操作步骤

### 1. 确定联动数据变量

首先确定需要联动的数据。例如：页面上方有两个选择组件，一个是下拉选项（选项内容为各个站点），另一个是日期选择器。此时需要定义两个交互变量，这里我们命名为 `stationName` 和 `recordTime`。

### 2. 创建页面接口

在系统中创建接口，接口名称可自定义。在参数清单中创建两条数据，分别为 `stationName` 和 `recordTime`。如果有默认值，可在创建时填入默认值。

![创建页面接口](/image/10.配置步骤/1769690747806.png)

### 3. 绑定接口到页面

在「页面配置 - 接口与参数」中，选中刚才创建的接口。

![绑定接口](/image/10.配置步骤/1769690814398.png)

### 4. 配置设置页面变量的组件

1. 添加一个卡片组组件，用于配置下拉选项和日期选择器
2. 创建卡片单元，打开卡片设计页面
3. 将下拉选项和日期选择器组件拖入卡片单元中

![拖入组件效果](/image/10.配置步骤/1769735432622.png)

4. 分别给下拉选项和日期选择器设置变量

**下拉选项配置：**

- 部件文本来源：变量
- 关联变量：`station_name`

![下拉选项变量配置](/image/10.配置步骤/1769735503440.png)

**日期选择器配置：**

- 部件文本来源：变量
- 关联变量：`record_time`

![日期选择器变量配置](/image/10.配置步骤/1769735557199.png)

### 5. 配置关联事件

进入页面详情，将 Tabs 翻到最右边，找到「关联事件」Tab，点击「添加事件」。需要分别添加两条事件：

- **事件类型 1**：获取页面变量
- **事件类型 2**：设置页面变量

#### 参数说明

| 参数项           | 说明                                                     |
| ---------------- | -------------------------------------------------------- |
| 事件名称         | 自定义名称，用于标识事件                                 |
| 事件类型         | 选择「获取页面变量」或「设置页面变量」                   |
| 组件变量         | 填写组件中使用的变量名，如 `station_name, record_time` |
| 归属页面组件编码 | 选择使用该事件的页面组件编码                             |
| 页面变量         | 填写页面中定义的变量名，如 `stationName, recordTime`   |

#### 注意事项

- 组件变量和页面变量的数量必须一致
- 组件变量和页面变量的顺序必须一致

### 6. 配置接口请求条件

创建一条接口请求，在请求调用条件中，使用页面接口参数作为变量。具体操作如下：

1. 变量来源选择「页面接口参数」
2. 选择页面接口
3. 选择该页面接口中的字段

![配置接口请求条件](/image/10.配置步骤/1769734638685.png)

### 7. 为列表组件配置接口请求

1. 接口数据类型选择「接口请求」
2. 接口编码选择上一步创建的请求编码

![列表组件接口配置](/image/10.配置步骤/1769735697545.png)

### 8. 测试组件联动效果

完成以上配置后，组件联动功能即可生效。下拉选项和日期选择器的值变化会自动触发关联接口请求，实现数据的动态更新。
