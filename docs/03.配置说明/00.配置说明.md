## PC 后台配置

PC 后台配置模块提供了丰富的列表配置功能，帮助您快速构建数据展示页面。

### 统计列表配置

统计列表配置用于创建和管理数据可视化统计列表，实现数据的分组统计、聚合展示，并以图表+表格的形式呈现。

**适用场景：**

- 数据概览页面
- 统计分析报表
- 多维度数据展示

**主要功能：**

- 分组统计：支持多字段分组
- 聚合计算：求和、平均值、计数等
- 图表展示：柱状图、折线图等
- 列表呈现：卡片列表样式

[查看详情](/features/list-config)

### 后台列表配置合并列

合并列功能允许在后台列表中，当相邻行的某个字段值相同时，自动合并这些单元格，使表格更加简洁清晰。

**适用场景：**

- 部门人员列表
- 分类数据展示
- 分组报表

**主要功能：**

- 自动单元格合并
- 多字段合并支持
- 灵活的配置方式

[查看详情](/features/list-merge-columns)

### PC 后台列表其它配置说明

more_config 是 PC 后台列表页面的核心配置项，用于控制列表的各种展示行为。

**配置功能：**

- 复选框控制（selection）
- 页面提示信息（pagePrompt）
- 统计配置（stats_cfg）
- 字段说明（col_explain、table_explain）
- 行操作按钮控制（isShowRowButtons）

[查看详情](/features/more-config)

## 自定义页面配置

自定义页面配置模块提供了灵活的可视化配置能力，支持创建个性化的数据展示页面。

### 柱状图分组配置

柱状图分组配置允许用户根据指定字段将数据分组展示，每个分组值对应一个独立的柱子。

**图表类型：**

- 普通柱状图
- 堆叠柱状图
- 渐变色柱状图

**配置选项：**

- 序列堆叠
- 自动渐变色
- 分组字段设置
- 数值字段配置

[查看详情](/features/bar-chart-grouping)

### 组件联动配置说明

组件联动功能实现组件间的数据交互，支持页面变量与组件变量的双向绑定。

**核心功能：**

- 页面变量定义
- 接口参数绑定
- 关联事件配置
- 动态数据更新

**应用场景：**

- 下拉选项与列表联动
- 日期选择与图表联动
- 多组件数据同步

[查看详情](/features/linkage/config-steps)

## 快速开始

### 环境准备

确保已正确配置系统环境，包括 Node.js、Vue CLI 等开发工具。

### 选择配置类型

根据您的需求选择合适的配置模块：

1. **需要数据统计展示** → 使用 [统计列表配置](/features/list-config)
2. **需要单元格合并效果** → 使用 [后台列表配置合并列](/features/list-merge-columns)
3. **需要高级列表功能** → 使用 [PC 后台列表其它配置说明](/features/more-config)
4. **需要图表分组展示** → 使用 [柱状图分组配置](/features/bar-chart-grouping)
5. **需要组件数据联动** → 使用 [组件联动配置说明](/features/linkage/config-steps)

### 配置流程

1. 创建服务接口请求
2. 定义列表或图表组件
3. 配置页面服务
4. 关联服务配置
5. 添加访问菜单
