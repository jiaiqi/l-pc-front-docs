> more_config 是 PC 后台列表页面的核心配置项，用于控制列表的各种展示行为，包括复选框、统计配置、字段说明等功能。

## 功能概述

more_config 配置用于定义 PC 后台列表页面的高级功能，通过 JSON 格式进行配置。主要包含以下功能模块：

- **selection**: 控制列表复选框的显示
- **pagePrompt**: 页面顶部提示信息配置
- **stats_cfg**: 列表统计数据配置
- **col_explain**: 列表字段解释说明
- **table_explain**: 表格字段解释说明（显示在列表顶部行按钮上方）
- **isShowRowButtons**: 控制行操作按钮的显示

## 配置参数说明

### 参数总览

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| selection | boolean | 否 | 是否显示复选框，默认 `false` |
| pagePrompt | object | 否 | 页面顶部提示信息配置 |
| stats_cfg | array | 否 | 统计配置数组 |
| col_explain | object | 否 | 列表字段解释说明 |
| table_explain | object | 否 | 表格字段解释说明 |
| isShowRowButtons | boolean | 否 | 是否显示行操作按钮，默认 `true` |

### selection 参数

用于控制列表是否显示复选框，支持多选操作。

```json
{
  "selection": true
}
```

**取值说明：**

- `true`: 显示复选框
- `false`: 隐藏复选框

### pagePrompt 参数

页面顶部提示信息的配置，支持自定义主题和描述内容。

```json
{
  "pagePrompt": {
    "type": "warning",
    "description": "<div style='color:black'>营业概览：门店的经营情况</div>"
  }
}
```

**参数说明：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | string | 是 | 主题类型，支持 `success`、`warning`、`info`、`error` |
| description | string | 是 | 提示描述内容，支持 HTML 格式 |

### stats_cfg 参数

统计配置数组，用于配置列表中显示的统计数据项。

```json
{
  "stats_cfg": [
    {
      "col": "real_income_amount_total",
      "type": "sum",
      "alias": "income_amount_sum_total",
      "unit": "￥",
      "label": "实收总额",
      "col_type": "Money",
      "tip": "周期内，实收总额为实际收到的金额..."
    }
  ]
}
```

**单条统计配置参数说明：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| col | string | 是 | 统计字段名，对应数据源的字段 |
| type | string | 是 | 统计类型，支持 `sum`（求和）、`avg`（平均值）、`count`（计数）等 |
| alias | string | 是 | 统计结果别名，用于前端展示 |
| unit | string | 是 | 单位符号，如 `￥`、`个`、`件` 等 |
| label | string | 是 | 统计项显示标签 |
| col_type | string | 是 | 数据类型，如 `Money`（金额）、`Number`（数字）等 |
| tip | string | 否 | 统计项的提示说明，鼠标悬停时显示 |

### col_explain 参数

列表字段的解释说明，配置后会显示在列表字段的相应位置。

```json
{
  "col_explain": {
    "desc": "列表字段解释说明"
  }
}
```

### table_explain 参数

表格字段的详细解释说明，配置后会显示在列表顶部行按钮上方。

```json
{
  "table_explain": {
    "desc": "<div style='color:white'>【实收总额】：周期内，实收总额为实际收到的金额...</div>"
  }
}
```

**使用说明：**

- 支持 HTML 格式的富文本内容
- 每个字段说明使用 `【字段名】：说明内容` 的格式
- 多个字段说明可以拼接在一起

### isShowRowButtons 参数

控制行操作按钮的显示，如编辑、删除等按钮。

```json
{
  "isShowRowButtons": false
}
```

**取值说明：**

- `true`: 显示行操作按钮
- `false`: 隐藏行操作按钮

## 常见使用场景

### 场景一：营业数据概览列表

在营业概览类列表中，通常需要展示多项统计数据，配合 pagePrompt 和 stats_cfg 使用：

```json
{
  "selection": true,
  "pagePrompt": {
    "type": "info",
    "description": "<div style='color:black'>营业概览：门店的经营情况</div>"
  },
  "stats_cfg": [
    {
      "col": "real_income_amount_total",
      "type": "sum",
      "alias": "income_amount_sum_total",
      "unit": "￥",
      "label": "实收总额",
      "col_type": "Money",
      "tip": "周期内，实收总额为实际收到的金额..."
    }
  ],
  "isShowRowButtons": true
}
```

### 场景二：财务报表列表

在财务报表类列表中，需要展示详细的字段说明，使用 table_explain 统一说明：

```json
{
  "selection": false,
  "table_explain": {
    "desc": "<div style='color:white'>【实收总额】：实际收到的金额...</div><div style='color:white'>【销售总额】：商品实际销售的金额...</div>"
  },
  "isShowRowButtons": false
}
```

### 场景三：数据统计列表

需要批量操作的数据统计列表，启用 selection 并隐藏行按钮：

```json
{
  "selection": true,
  "isShowRowButtons": false,
  "stats_cfg": [...]
}
```

## 注意事项

1. **配置优先级**: 所有配置项均为可选，不配置时使用系统默认值
2. **HTML 安全性**: `description` 和 `table_explain.desc` 支持 HTML，但应避免使用复杂的 JavaScript 代码
3. **字段匹配**: `stats_cfg` 中的 `col` 字段必须与数据源中的字段名保持一致
4. **类型规范**: `col_type` 应使用规范的数据类型标识，以确保正确的格式化显示
5. **样式兼容性**: 内联样式应考虑不同主题的兼容性，建议使用通用样式
