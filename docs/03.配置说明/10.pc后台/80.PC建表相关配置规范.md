# PC 建表相关配置规范

> **PC 后台数据库表结构设计、字段命名及服务配置规范**

本文档规定了 PC 后台系统中数据库表、字段、服务的命名规范以及页面表单设计准则，确保系统的一致性和可维护性。

## 概述

命名需遵循见名知意原则，使用英文单词缩写或简写，保持简洁明了。

## 表名规范

### 命名规则

| 序号 | 规范项     | 说明                                            |
| ---- | ---------- | ----------------------------------------------- |
| 1    | 命名格式   | `bx应用编号_自定义名称`，遵循下划线命名法     |
| 2    | 大小写     | 全部小写，避免前后端取值时因大小写误写导致错误  |
| 3    | 长度限制   | 整体命名长度小于 25 个字符（Oracle 数据库限制） |
| 4    | 数字限制   | 不能包含数字，带数字的表平台默认为日期分表      |
| 5    | 下划线位置 | 不能以下划线开头或结尾                          |

### 示例

| 规范示例          | 说明           |
| ----------------- | -------------- |
| `bxsys_user`    | 系统用户表     |
| `bxorder_main`  | 订单主表       |
| `bxhr_employee` | 人力资源员工表 |

## 字段规范

### 命名规则

| 序号 | 规范项     | 说明                                                             |
| ---- | ---------- | ---------------------------------------------------------------- |
| 1    | 大小写     | 全部小写，遵循下划线命名法                                       |
| 2    | 长度限制   | 整体命名长度小于 20 个字符（不同数据库限制）                     |
| 3    | 下划线位置 | 不能以下划线开头或结尾（下划线结尾字段平台统一当作加密字段处理） |
| 4    | 数字限制   | 字段名不能包含数字                                               |
| 5    | 中文名长度 | 一般不要超过 8 个字符（表单显示 label 时会显示不全）             |

### 公共字段

平台创建的表必须包含以下公共字段：

| 字段名               | 说明         |
| -------------------- | ------------ |
| `id`               | 主键 ID      |
| `create_time`      | 创建时间     |
| `create_user`      | 创建人       |
| `create_user_disp` | 创建人显示名 |
| `modify_time`      | 修改时间     |
| `modify_user`      | 修改人       |
| `modify_user_disp` | 修改人显示名 |
| `del_flag`         | 删除标志     |

**说明**：通过平台创建的表会自动创建上述公共字段。

### 必填字段设置

- 数据库字段非必填，除非业务场景非常明确
- 避免批量导入数据时因必填字段无值导致导入失败
- 特定情况必填的通过应用表单校验完成

## 自定义服务命名规范

### 服务类型命名规则

| 服务类型 | 命名格式                     | 示例                      |
| -------- | ---------------------------- | ------------------------- |
| 查询服务 | `srv应用编号_名称_select`  | `srvbxsys_user_select`  |
| 增加服务 | `srv应用编号_名称_add`     | `srvbxsys_user_add`     |
| 修改服务 | `srv应用编号_名称_update`  | `srvbxsys_user_update`  |
| 删除服务 | `srv应用编号_名称_delete`  | `srvbxsys_user_delete`  |
| 操作服务 | `srv应用编号_名称_operate` | `srvbxsys_user_operate` |

### 命名要求

- 全部小写，遵循下划线命名法
- 整体命名长度小于 20 个字符
- 不能以下划线开头或结尾
- 字段名不能包含数字

## 特殊表字段要求

### 树形表字段

树形表必须包含以下字段：

| 字段名        | 说明         | 要求                 |
| ------------- | ------------ | -------------------- |
| `parent_no` | 父节点编号   | 指向本表 `no` 字段 |
| `name_path` | 名称路径     | 需在表定义中设置     |
| `is_leaf`   | 是否叶子节点 | 名称固定             |
| `path`      | 路径         | 名称固定             |

### 流程表字段

流程表必须包含以下字段：

| 字段名               | 说明         |
| -------------------- | ------------ |
| `proc_status`      | 流程状态     |
| `proc_instance_no` | 流程实例编号 |

## 唯一性字段要求

### 设计要求

1. 每张表设计时必须包含一个字段来确定当前行数据（`id` 字段除外），以便后续被其他表引用
2. 唯一性字段如果为编号字段，尽量通过系统自动编号生成

### 示例

| 表名             | 唯一性字段   | 生成方式 |
| ---------------- | ------------ | -------- |
| `bxsys_user`   | `user_no`  | 自动编号 |
| `bxorder_main` | `order_no` | 自动编号 |

## 页面表单设计规范

### 字段布局

| 字段类型 | 表单宽度 | 说明              |
| -------- | -------- | ----------------- |
| 数字类型 | 1/4      | 占用表单 1/4 宽度 |
| 下拉选项 | 1/4      | 占用表单 1/4 宽度 |

### 字段分组

- 具备相同属性的字段一般放置到同一组或挨着
- 查询字段一般不要超过 4 个（为了页面视觉效果）

### 默认值设置

- 枚举或集合类型字段，表单初始需要给默认值
- 根据业务场景自行设置

## 外键关系规范

### 设计原则

1. 被引用表必须创建自动编号字段，供其他表引用
2. 表间关系不生成实际的物理外键
3. 级联删除通过平台内部配置实现

### 示例

```
表 A: bxsys_department
  - dept_no (自动编号，被引用字段)

表 B: bxsys_user
  - dept_no (引用表 A 的 dept_no)
```

## 规范检查清单

### 建表前检查

- [ ] 表名是否符合命名规范
- [ ] 表名长度是否小于 25 个字符
- [ ] 是否包含公共字段
- [ ] 是否设计了唯一性字段

### 字段设计检查

- [ ] 字段名是否全部小写
- [ ] 字段名长度是否小于 20 个字符
- [ ] 中文名是否不超过 8 个字符
- [ ] 必填设置是否合理

### 服务命名检查

- [ ] 服务名是否符合对应类型的命名格式
- [ ] 服务名长度是否小于 20 个字符
