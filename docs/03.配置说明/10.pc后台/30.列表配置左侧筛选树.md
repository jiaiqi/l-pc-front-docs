# 列表配置左侧筛选树

> **配置列表页面左侧分类筛选树，实现数据快速过滤功能**

本文档介绍如何在 PC 后台列表页面配置左侧筛选树，通过树形分类结构对列表数据进行筛选，提升数据检索效率。

## 功能说明

左侧筛选树功能允许在列表页面左侧展示树形分类结构，用户可以通过点击树节点快速筛选列表数据。适用于具有层级分类的数据展示场景，如部门人员、产品分类、地区数据等。

## 配置步骤

### 1. 配置列表组件

进入「配置监控 - DIY 页面 - 组件定义 - 列表」，增加一条列表配置。

**操作步骤：**

1. 在列表选项中选中「树分类筛选」

![列表配置](/image/30.列表配置左侧筛选树/1772673296097.png)

2. 配置树分类筛选相关字段

**树分类筛选配置项：**
![树分类筛选配置](/image/30.列表配置左侧筛选树/1772673352055.png)

### 2. 创建页面服务

进入「系统（平台配置）- 页面配置 - 页面服务」，新建一条页面服务数据。

**配置说明：**

- 页面服务用于定义列表的个性化配置和展示UI
- 配置左侧树分类筛选的话需要绑定对应的列表配置

![创建页面服务](/image/30.列表配置左侧筛选树/1772673090360.png)

### 3. 配置列表样式

在页面服务配置中，选择列表样式：

**选项说明：**

| 列表类型 | 说明 | 适用场景 |
|----------|------|----------|
| 选择卡片列表 | 以卡片形式展示数据 | 数据字段较少、需要图文展示 |
| 单行列表 | 普通表格形式展示 | 数据字段较多、密集数据展示 |

**配置步骤：**

1. 选项选择「列表样式」
2. 列表类型选择「选择卡片列表」或「单行列表」
3. 列表 No 选择刚刚创建的列表配置

![列表样式配置](/image/30.列表配置左侧筛选树/1772673162455.png)

### 4. 绑定页面服务

服务管理里面，找到列表页面的 select 服务，点击编辑，在下方配置编码选择刚刚创建的页面服务配置。

**操作说明：**

1. 定位到列表页面的数据查询服务
2. 编辑服务配置
3. 在「配置编码」字段选择步骤 2 创建的页面服务

![绑定页面服务](/image/30.列表配置左侧筛选树/1772673485838.png)

## 配置要点

### 字段映射关系

| 树配置字段 | 列表字段 | 作用 |
|------------|----------|------|
| 树值字段 | 筛选关联字段 | 点击树节点时，使用该字段值筛选列表 |
| 父子关联字段 | - | 构建树形层级结构 |

### 注意事项

- 树数据源服务必须包含父子关联字段，用于构建层级结构
- 树值字段和列表的筛选关联字段类型必须一致
- 若树数据量大，建议配置异步加载或懒加载

## 使用场景示例

### 场景一：部门人员筛选

**需求：** 在人员列表左侧展示部门树，点击部门筛选该部门下的人员。

**配置：**

| 配置项 | 值 |
|--------|-----|
| 树数据源 | srvbxsys_dept_select |
| 树节点字段 | dept_name |
| 树值字段 | dept_no |
| 父子关联字段 | parent_no |
| 筛选关联字段 | dept_no |

### 场景二：产品分类筛选

**需求：** 在产品列表左侧展示产品分类树，点击分类筛选该分类下的产品。

**配置：**

| 配置项 | 值 |
|--------|-----|
| 树数据源 | srvbxsys_product_category_select |
| 树节点字段 | category_name |
| 树值字段 | category_no |
| 父子关联字段 | parent_no |
| 筛选关联字段 | category_no |

## 常见问题

### Q: 树形数据不显示？

A: 检查以下几点：
1. 树数据源服务是否正常返回数据
2. 父子关联字段配置是否正确
3. 树数据源中是否存在循环引用（如 A 的父节点是 B，B 的父节点是 A）

### Q: 点击树节点后列表数据未筛选？

A: 检查以下几点：
1. 树值字段和列表筛选关联字段是否配置正确
2. 列表的 select 服务是否正确绑定了页面服务
3. 筛选关联字段是否存在于列表数据中

### Q: 树形层级显示不正确？

A: 检查以下几点：
1. 父子关联字段值是否正确（根节点的 parent_no 应为 null 或空字符串）
2. 是否存在多个根节点（树形结构只能有一个根节点）
3. 数据是否存在断层（如子节点的父节点不存在）
