# 🚀 构建部署文档

> **l-pc-front 项目构建、部署与环境配置完整指南**

## 📋 构建部署概览

### 架构流程图
```
┌─────────────────────────────────────────────────────────────┐
│                    开发环境 (Development)                   │
│  源代码 → 本地开发 → 代码检查 → 本地测试 → 热更新          │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    构建环境 (Build)                         │
│  环境配置 → 代码压缩 → 资源优化 → 代码分割 → 产物生成      │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    部署环境 (Deployment)                    │
│  产物上传 → 服务器配置 → CDN加速 → 域名绑定 → 监控告警     │
└─────────────────────────────────────────────────────────────┘
```

---

## 🛠️ 开发环境配置

### 1. 环境要求

```bash
# 核心版本
Node.js: 18.20.8 (推荐使用 Volta 管理)
Yarn: 1.22.22
Vue CLI: 3.12.1

# 检查版本
node -v  # 应该显示 v18.20.8
yarn -v  # 应该显示 1.22.22
```

### 2. 项目初始化

```bash
# 1. 克隆项目
git clone https://gitee.com/njy_3/l-pc-front.git
cd l-pc-front
