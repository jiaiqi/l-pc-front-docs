# 柱状图分组配置

> 本文档介绍如何配置根据某个字段分组的柱状图，包括基本配置、堆叠柱状图、渐变色设置等高级功能。

## 概述

柱状图分组配置允许用户根据指定字段将数据分组展示，每个分组值对应一个独立的柱子。通过灵活的配置选项，可以实现普通柱状图、堆叠柱状图、渐变色柱状图等多种展示效果。

## 配置步骤

### 1. 输入图表名称

在图表配置界面的基本信息区域，输入图表的名称。

::: tip 提示
图表名称应简洁明了，能够准确反映图表展示的数据内容，例如"销售业绩统计"、"用户增长趋势"等。
:::

### 2. 选择图表类型

在图表类型下中，选择"柱状图"。

### 3. 配置更多选项

在更多选项区域，可以根据需要配置以下高级功能：

#### 3.1 序列堆叠

如果需要创建堆叠柱状图，勾选"序列堆叠"选项。

**堆叠柱状图效果**：

- 将同一分类下的多个数据系列垂直堆叠显示
- 便于比较各分类的总值以及各系列的占比
- 适用于展示部分与整体的关系

::: warning 注意
启用序列堆叠后，y1指标名称配置的分组字段将决定堆叠的系列数量。
:::

#### 3.2 自动渐变色

如果需要柱状图的柱子使用渐变色，勾选"自动渐变色"选项。

**渐变色效果**：

- 每个数据系列自动应用不同的渐变色
- 提升图表的视觉效果和可读性
- 系统会根据系列数量自动分配颜色!

### 4. 配置y1指标名称

在y1指标名称配置框中，输入用于分组的字段名称。

**配置说明**：

- 该字段的不同值将决定图表中的分组数量
- 每个不同的字段值对应一个独立的柱子
- 如果是折线图，则对应不同的线条

**示例**：

- 分组字段为"部门"，数据中有"销售部"、"技术部"、"市场部"三个值
- 图表将显示三根柱子，分别代表三个部门的数据

::: tip 提示
y1指标名称字段应为离散型数据（如部门、产品类型、地区等），而非连续型数据。
:::

### 5. 配置y1指标值字段

在y1指标值字段配置框中，输入数值类型的字段名称。

**配置说明**：

- 该字段用于计算每个分组的数值大小
- 决定柱子的高度或线条的数据点
- 必须为数值类型（整数或小数）

**示例**：

- 指标值字段为"sales(销售额)"
- 每个部门的销售额将决定对应柱子的高度

::: danger 警告
y1指标值字段必须是数值类型，否则图表将无法正常渲染。
:::

### 6. 配置轴标签（分类x轴）字段

在轴标签（分类x轴）字段配置框中，配置x轴数据对应的字段。

**配置说明**：

- 该字段决定x轴的分类标签
- 每个不同的字段值对应x轴上的一个刻度
- 通常为时间、类别等维度字段

**示例**：

- 轴标签字段为"month"
- x轴将显示"1月"、"2月"、"3月"等月份标签

## 字段关系说明

### y1指标名称与图表系列的关系

| y1指标名称字段值 | 图表系列数量 | 系列命名             |
| ---------------- | ------------ | -------------------- |
| 不配置           | 1个系列      | 使用默认名称         |
| 单一值           | 1个系列      | 使用该值作为系列名称 |
| 多个不同值       | 多个系列     | 每个值对应一个系列   |

### y1指标值字段的作用

- 决定每个数据点的高度（柱状图）或数值（折线图）
- 必须为数值类型
- 支持聚合计算（如求和、平均值等）

### 轴标签字段的作用

- 决定x轴的分类刻度
- 每个唯一值对应一个x轴位置
- 通常为时间、类别等维度

## 常见问题

### Q: 为什么图表没有显示数据？

A: 请检查以下几点：

1. y1指标值字段是否为数值类型
2. 数据源中是否包含对应字段
3. 轴标签字段是否有数据
4. 服务接口是否正常返回数据

### Q: 如何调整柱子的颜色？

A: 有三种方式：

1. **自动渐变色**：勾选"自动渐变色"，系统自动将内置的颜色数组改为对应的渐变色
2. **内置颜色数组**：不勾选"自动渐变色"，使用内置的颜色数组（见上方"默认颜色数组"）
3. **自定义图例颜色**：若配置了图例颜色，则使用图例颜色，图例颜色格式为用逗号分隔的字符串，建议使用16进制格式比如 `#009688`

### Q: 堆叠柱状图和普通柱状图有什么区别？

A:

- **柱状图**：同一分类下的多个系列并排显示，便于比较各系列的数值
- **堆叠柱状图**：同一分类下的多个系列垂直堆叠，便于比较各分类的总值及各系列的占比

### Q: 如何将柱状图改为折线图？

A: 在图表类型中选择"折线图"即可，其他配置保持不变。y1指标名称的不同值将对应不同的线条。

## 最佳实践

### 1. 合理选择图表类型

- **分组柱状图**：适用于比较多个系列在同一分类下的数值
- **堆叠柱状图**：适用于展示部分与整体的关系
- **折线图**：适用于展示数据的趋势变化

### 2. 合理使用渐变色

- 多系列图表建议勾选"自动渐变色"，提升可读性
- 单系列图表可以不勾选，保持简洁统一

### 3. 合理设置字段

- y1指标名称：选择离散型数据，如部门、产品、地区等
- y1指标值字段：选择数值型数据，如销售额、数量、金额等
- 轴标签字段：选择时间或类别型数据，如日期、月份、季度等

### 4. 图表命名规范

- 图表名称应简洁明了
- 能够准确反映图表展示的数据内容
- 避免使用过于笼统的名称，如"统计图表"、"数据分析"等
