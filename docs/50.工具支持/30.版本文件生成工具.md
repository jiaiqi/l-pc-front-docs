# 版本文件生成工具

> **交互式版本文件生成工具，自动创建包含版本信息的 JSON 文件**

本文档介绍项目中使用的版本文件生成工具，帮助开发者自动生成包含版本号、构建号、提交时间等信息的 `version.json` 文件，便于前端应用进行版本管理和更新检查。

## 功能特性

- **交互式命令行界面**：友好的交互体验，引导式操作流程
- **自动获取版本信息**：从 Git 标签和提交记录自动提取版本信息
- **多种描述生成方式**：支持自动获取提交日志或手动输入
- **智能编辑器集成**：支持多种编辑器编辑版本描述
- **提交记录格式化**：自动格式化提交记录，添加分隔符
- **临时文件管理**：自动生成和清理临时编辑文件
- **多平台支持**：兼容 Windows、macOS、Linux 系统

## 前置条件

在使用本工具前，请确保已安装以下依赖：

- **Node.js** >= 18.20.8
- **Git** >= 2.0
- **dayjs**（项目依赖）

## 使用方法

### 启动工具

在项目根目录下运行以下命令启动工具：

```bash
node scripts/generate-version.js
```

或通过 npm 脚本运行：

```bash
npm run generate-version
```

### 操作流程

#### 1. 显示版本信息

工具启动后会显示当前版本和构建信息：

```
╔══════════════════════════════════════╗
║ 🚀 版本文件生成工具                  ║
╚══════════════════════════════════════╝
ℹ 当前版本: v1.2.3
ℹ 当前构建: abc1234
```

**信息说明：**

| 字段 | 来源 | 说明 |
|------|------|------|
| 当前版本 | Git 最新标签 | 如 `v1.2.3`，如果没有标签则显示 `latest` |
| 当前构建 | Git Commit Hash | 短版本，如 `abc1234` |

#### 2. 选择描述生成方式

工具提供三种描述生成方式：

```
═══ 选择描述生成方式 ═══
  1. 自动使用上次 tag 以来的提交日志
  2. 使用最近几次提交日志
  3. 手动输入

请输入选项编号 (默认: 1)
```

**选项说明：**

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| 1 | 自动获取自上次标签以来的所有提交 | 正常版本发布 |
| 2 | 获取最近 N 次提交 | 快速生成版本文件 |
| 3 | 完全手动输入 | 自定义版本描述 |

#### 3. 选项 1：自动获取提交日志

选择此选项后，工具会自动获取自上次标签以来的提交记录：

```
ℹ 正在获取上次 tag 以来的提交日志...
```

**获取逻辑：**
1. 获取最近的 Git 标签
2. 执行 `git log <latestTag>..HEAD` 获取提交记录
3. 格式化输出，添加分隔符

**输出示例：**

```
2025-01-30 10:00 【abc1234】
feat: 添加用户登录功能

文件:
src/components/Login.vue
src/api/user.js
===========================
2025-01-29 15:30 【def5678】
fix: 修复表格排序问题

文件:
src/components/Table.vue
```

**如果没有找到标签：**

```
⚠️  警告: 未找到上次 tag，将使用最近 10 次提交日志
```

#### 4. 选项 2：获取最近 N 次提交

选择此选项后，需要输入要获取的提交数量：

```
请输入要获取最近几次提交日志 (默认: 10)
```

输入数字后，工具会获取指定数量的最近提交：

```
ℹ 正在获取最近 10 次提交日志...
```

#### 5. 选项 3：手动输入

选择此选项后，可以手动输入版本描述：

```
═══ 请输入自定义描述 ═══
请输入多行描述内容，输入空行结束：
> 第一行描述
> 第二行描述
> 
```

输入空行表示结束输入。

#### 6. 编辑描述（可选）

生成描述后，可以选择是否编辑：

```
═══ 生成的描述 ═══
────────────────────────────────────────
2025-01-30 10:00 【abc1234】
feat: 添加用户登录功能
...
────────────────────────────────────────

是否需要编辑描述? (y/N)
```

选择 `y` 后，会打开编辑器进行编辑。编辑完成后显示预览：

```
═══ 编辑后的描述 ═══
────────────────────────────────────────
[编辑后的内容]
────────────────────────────────────────

请选择操作:
  y - 按照该描述生成版本文件
  n - 再次编辑描述
  q - 退出生成版本文件

请输入选项 (默认: y)
```

**支持的编辑器：**

| 平台 | 编辑器 | 优先级 |
|------|--------|--------|
| Windows | Notepad++ | 1 |
| Windows | VSCode | 2 |
| Windows | 记事本 | 3（保底） |
| Linux/Mac | Nano | 1 |
| Linux/Mac | Vim | 2 |
| Linux/Mac | VSCode | 3 |

#### 7. 生成版本文件

确认后，工具会生成 `version.json` 文件：

```

ℹ 输出路径: ./public/version.json

{
  "version": "v1.2.3",
  "build": "abc1234",
  "commitTime": "2025-01-30 10:00:00 +0800",
  "buildTime": "2025-01-30 14:30:00",
  "tagDescription": "2025-01-30 10:00 【abc1234】\nfeat: 添加用户登录功能\n..."

```

### 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| version | string | 版本号（Git 标签） | `v1.2.3` |
| build | string | 构建号（Commit Hash） | `abc1234` |
| commitTime | string | Git 提交时间 | `2025-01-30 10:00:00 +0800` |
| buildTime | string | 构建时间 | `2025-01-30 14:30:00` |
| tagDescription | string | 版本描述 | 提交日志 |

## 核心功能实现

### 获取 Git 信息

```javascript
// 获取 Git Commit Hash (短版本)
const commitHash = execSync('git rev-parse --short HEAD').toString().trim();

// 获取 Git 提交时间
const commitTime = execSync('git log -1 --format=%cd --date=iso').toString().trim();

// 获取最近的 Tag
let gitTag = '';
try {
  gitTag = execSync('git describe --tags --abbrev=0').toString().trim();
} catch (e) {
  gitTag = 'latest';
}
```

### 获取提交日志

```javascript
const getCommitLogsSinceLastTag = () => {
  try {
    // 获取最近的 tag
    const latestTag = execSync('git describe --tags --abbrev=0', { stdio: 'pipe' }).toString().trim();

    // 获取自上次 tag 以来的提交日志
    const commitLogs = execSync(
      `git log ${latestTag}..HEAD --pretty=format:"%ad 【%h】%n%s%n%b%n文件: " --date=format:"%Y-%m-%d %H:%M" --name-only --reverse --no-merges`,
      { stdio: 'pipe' }
    ).toString().trim();

    if (commitLogs) {
      // 在每个提交之间添加分隔符
      const lines = commitLogs.split('\n');
      const formattedLogs = [];
      
      for (let i = 0; i < lines.length; i++) {
        // 检测到新的提交开始（日期行）且不是第一个提交
        if (lines[i].match(/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}/) && i > 0) {
          formattedLogs.push('===========================');
        }
        formattedLogs.push(lines[i]);
      }
      
      return formattedLogs.join('\n');
    }
    return '暂无提交记录';
  } catch (error) {
    return null;
  }
};
```

### 生成版本文件

```javascript
const versionInfo = {
  version: gitTag,
  build: commitHash,
  commitTime: commitTime,
  buildTime: dayjs().format('YYYY-MM-DD HH:mm:ss'),
  tagDescription: tagDescription,
};

const outputDir = './public';
if (!fs.existsSync(outputDir)) {
  fs.mkdirSync(outputDir, { recursive: true });
}

fs.writeFileSync(`${outputDir}/version.json`, JSON.stringify(versionInfo, null, 2));
```

## 使用场景

### 1. 版本发布

在发布新版本时生成版本文件：

```bash
# 1. 创建 Git 标签
npm run git-tag

# 2. 生成版本文件
npm run generate-version

# 3. 构建项目
npm run build
```

### 2. CI/CD 集成

在 CI/CD 流程中自动生成版本文件：

```yaml
# .github/workflows/deploy.yml
- name: Generate Version
  run: node scripts/generate-version.js
  
- name: Build
  run: npm run build
```

### 3. 前端更新检查

前端应用可以使用 `version.json` 进行更新检查：

```javascript
// 检查更新
const checkUpdate = async () => {
  const response = await fetch('/version.json');
  const versionInfo = await response.json();
  
  const currentVersion = localStorage.getItem('appVersion');
  if (currentVersion !== versionInfo.version) {
    // 发现新版本
    showUpdateNotification(versionInfo);
  }
};
```

## 常见问题

### Q: 版本文件没有生成怎么办？

A: 检查以下几点：
1. 确保在项目根目录运行命令
2. 检查 `public` 目录是否有写入权限
3. 查看控制台错误信息

### Q: 版本号显示为 `latest`？

A: 这表示没有找到 Git 标签。解决方法：
1. 创建 Git 标签：`git tag v1.0.0`
2. 推送标签到远程：`git push origin v1.0.0`

### Q: 如何自定义版本文件路径？

A: 修改脚本中的 `outputDir` 变量：

```javascript
const outputDir = './dist'; // 修改为自定义路径
```

### Q: 提交日志获取失败？

A: 可能的原因：
1. 当前目录不是 Git 仓库
2. Git 命令执行失败
3. 没有提交记录

### Q: 如何添加更多字段到版本文件？

A: 修改 `versionInfo` 对象：

```javascript
const versionInfo = {
  version: gitTag,
  build: commitHash,
  commitTime: commitTime,
  buildTime: dayjs().format('YYYY-MM-DD HH:mm:ss'),
  tagDescription: tagDescription,
  // 添加自定义字段
  environment: process.env.NODE_ENV,
  branch: execSync('git rev-parse --abbrev-ref HEAD').toString().trim(),
};
```
