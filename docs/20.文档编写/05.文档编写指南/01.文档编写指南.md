## 创建新文档

### 基本步骤

1. **选择目录位置**

   在 `docs/` 目录下选择合适的文件夹，如：
   - `01.指南/` - 项目指南类文档
   - `02.架构设计/` - 架构设计类文档
   - `03.核心功能/` - 核心功能类文档
   - `04.开发指南/` - 开发指南类文档
   - `05.部署运维/` - 部署运维类文档
   - `06.故障排查/` - 故障排查类文档
   - `07.工具支持/` - 工具支持类文档
   - `20.文档编写/` - 文档编写类文档

2. **创建 Markdown 文件**

   ```bash
   # 示例：在指南目录下创建新文档
   touch docs/01.指南/01.简介/02.新功能介绍.md
   ```

3. **编写 Frontmatter**

   每个 Markdown 文件都需要在文件开头添加 Frontmatter 配置：

   ```yaml
   ---
   title: 文档标题
   date: 2025-01-07 10:00:00
   permalink: /guide/new-feature
   categories:
     - 指南
   tags:
     - 新功能
     - 教程
   sidebar: true
   sidebarSort: 2
   ---
   ```

4. **编写文档内容**

   使用 Markdown 语法编写文档内容。

### 文档模板

以下是完整的文档模板：

```yaml

## Frontmatter 配置

### 基本配置项

| 配置项 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `title` | string | 文档标题 | `title: 文档标题` |
| `date` | string | 创建/更新日期 | `date: 2025-01-07 10:00:00` |
| `permalink` | string | 永久链接（URL路径） | `permalink: /guide/example` |
| `categories` | array | 分类列表 | `categories: ['指南', '开发']` |
| `tags` | array | 标签列表 | `tags: ['Vue', '教程']` |
| `sidebar` | boolean | 是否显示在侧边栏 | `sidebar: true` |
| `sidebarSort` | number | 侧边栏排序（数值越小越靠前） | `sidebarSort: 10` |
| `top` | boolean | 是否置顶 | `top: true` |
| `article` | boolean | 是否为文章（用于归档） | `article: true` |
| `layout` | string | 布局类型 | `layout: home` |

## 侧边导航配置

### 自动生成侧边栏

本项目使用 **vitepress-theme-teek** 主题，支持**自动生成侧边栏**。侧边栏会根据目录结构自动生成。

#### 目录命名规则

**博客风格（推荐）**：

- 文件夹和文件名使用序号前缀：`01.文件夹名`、`02.文件名.md`
- 序号决定在侧边栏中的显示顺序
- 建议使用间隔序号：`10、20、30`，方便插入新文档

```
docs/
├─ 01.指南/
│  ├─ 01.简介/
│  │  ├─ 01.项目概览.md
│  │  └─ 05.快速开始.md
│  └─ 05.使用/
│     ├─ 10.登录认证.md
│     └─ 15.权限认证.md
```

**文档风格**：

- 文件名使用英文（作为 URL）
- 使用 `sidebarSort` 配置排序

```
docs/
├─ guide/
│  ├─ overview.md
│  └─ quickstart.md
```

#### 侧边栏排序

**方法1：文件名序号**

```yaml
---
title: 快速开始
permalink: /guide/quickstart
# 文件名：05.快速开始.md
# 侧边栏会根据序号 05 排序
---
```

**方法2：sidebarSort 配置**

```yaml
---
title: 快速开始
permalink: /guide/quickstart
sidebarSort: 10
# 数值越小越靠前
---
```

**方法3：全局配置默认值**

在 `docs/.vitepress/teekConfig.ts` 中配置：

```typescript
import { defineTeekConfig } from "vitepress-theme-teek/config";

export const teekConfig = defineTeekConfig({
  vitePlugins: {
    sidebarOption: {
      sort: true,
      defaultSortNum: 9999,
      sortNumFromFileName: false,
    },
  },
});
```

### 手动配置侧边栏

如果需要手动配置侧边栏，在 `docs/.vitepress/config.ts` 中取消注释并修改 `sidebar` 配置：

```typescript
export default defineConfig({
  themeConfig: {
    sidebar: {
      "/guide/": [
        {
          text: "📚 指南",
          items: [
            { text: "项目概览", link: "/guide/overview" },
            { text: "快速开始", link: "/guide/quickstart" },
            {
              text: "高级功能",
              items: [
                { text: "功能1", link: "/guide/feature1" },
                { text: "功能2", link: "/guide/feature2" },
              ],
            },
          ],
        },
      ],
    },
  },
});
```

### 侧边栏折叠

在 `docs/.vitepress/teekConfig.ts` 中配置：

```typescript
export const teekConfig = defineTeekConfig({
  sidebarTrigger: true,
});
```

## 分类和标签

### 设置分类

在 Frontmatter 中添加 `categories` 字段：

```yaml
---
title: 文档标题
categories:
  - 指南
  - 开发
---
```

### 设置标签

在 Frontmatter 中添加 `tags` 字段：

```yaml
---
title: 文档标题
tags:
  - Vue
  - 教程
  - 最佳实践
---
```

### 分类和标签的作用

1. **分类页面**：访问 `/categories` 查看所有分类
2. **标签页面**：访问 `/tags` 查看所有标签
3. **文章归档**：分类和标签用于文章归档和筛选
4. **SEO优化**：有助于搜索引擎索引

### 查看分类和标签页面

- 分类页：`http://localhost:5173/categories`
- 标签页：`http://localhost:5173/tags`

## 特殊目录说明

### @pages 目录

存放特殊页面，不会被 Teek 扫描生成侧边栏：

```
docs/
└─ @pages/
   ├─ categoriesPage.md
   ├─ tagsPage.md
   ├─ archivesPage.md
   └─ articleOverviewPage.md
```

### @fragment 目录

存放碎片化文章，不会自动生成侧边栏：

```
docs/
└─ @fragment/
   ├─ 代码片段.md
   └─ 常用命令.md
```

### .scripts 目录

存放脚本和工具文件，不会被 Teek 扫描：

```
docs/
└─ .scripts/
   └─ generate-docs.js
```

### 目录页目录

以 `目录页` 命名的目录（如 `01.目录页`），不会被统计到文章总数：

```
docs/
└─ 01.目录页/
   └─ index.md
```

## 常见问题

### Q1: 侧边栏没有显示？

**A:** 检查以下几点：
1. 确保 `sidebar: true` 已配置
2. 确保文档不在特殊目录（@pages、@fragment等）
3. 检查文件名是否符合命名规则

### Q2: 分类和标签页面为空？

**A:** 确保：
1. 文档中正确配置了 `categories` 和 `tags`
2. 访问 `/categories` 和 `/tags` 页面
3. 确保使用了正确的页面配置（`categoriesPage: true`、`tagsPage: true`）

### Q3: 如何修改文档 URL？

**A:** 使用 `permalink` 配置：

```yaml
---
title: 文档标题
permalink: /custom/url/path
---
```

### Q4: 图片无法显示？

**A:** 检查以下几点：
1. 图片是否在 `docs/public/` 目录下
2. 图片路径是否正确（以 `/` 开头）
3. 图片文件名是否正确

### Q5: 如何添加代码块复制功能？

**A:** 已在 `teekConfig.ts` 中配置：

```typescript
codeBlock: {
  copiedDone: (TkMessage) => TkMessage.success("复制成功！"),
},
```

## 最佳实践

### 1. 文档命名规范

- 使用清晰的中文标题
- 使用序号前缀控制排序
- 保持文件名与 `title` 一致

### 2. 目录组织

- 按功能模块组织文档
- 使用合理的目录层级（不超过5层）
- 为每个目录添加 `index.md`

### 3. Frontmatter 配置

- 每个文档都配置完整的 Frontmatter
- 使用 `permalink` 设置友好的 URL
- 合理使用 `categories` 和 `tags`

### 4. 内容编写

- 使用 Markdown 标准语法
- 添加适当的代码示例
- 使用提示框强调重要信息

### 5. 图片管理

- 使用有意义的图片文件名
- 压缩图片大小
- 添加图片描述（alt属性）
